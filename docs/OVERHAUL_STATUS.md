# 풀이 개편 현황 (2026-11-23 기준)

개편의 목적, 직접 확인한 근거, 구현된 것, 우리의 인위적 개입, 데이터, 열린 결정을 한 곳에 모은 문서입니다.
구조와 코드 설명은 `READING_ENGINE.md`, 이 문서는 "지금 어디까지 왔고 무엇이 남았나"를 다룹니다.

## 1. 왜, 무엇을 바꾸는가

- 예전: 부위별 점수를 더하고 인구 평균과 비교해 문장을 고르는 상향식.
- 지금 방향: 마의상법의 읽는 순서를 따르는 하향식. 전체 틀을 먼저 보고, 어긋난 부분을 짚어 나이와 연결한다.
- 순서: 1 형(오행형) 2 틀(삼정 균등) 3 예외(짝 부위) 4 지금의 나이(유년) 5 인연.
- 인연, 잘 맞는 사람, 피해야 할 인연은 개편이 성공할 때까지 기존 방식 그대로 둔다.
- 기준: 확인된 것부터 구현한다. 근거가 부족하면 딥서칭 후 보고하고 승인받는다. 임의로 정한 값은 이름 붙은 상수와 "ARTIFICIAL" 주석으로 남기고 문서에 기록한다.
- 실제 관상가의 검수는 아직 받지 않았다.

## 2. 직접 확인한 근거

직접 읽은 자료: 사주포럼 마의상법 01~09쪽(비공식 번역, 한문과 번역이 어긋난 곳이 있음), 대전대 한의학연구소 논문집 21(2) 2013, 한국민족문화대백과 관상, 麻衣相法 卷二 相鼻相口(yixiangqiankun.com/zh-tw/27160.htm).

- 관찰 순서: 기색, 음성, 신의 동태, 용모. 오형, 오관, 오악, 삼부, 삼정, 삼재, 오성, 육요, 십이궁, 사학당, 팔학당 순.
- 삼정: 「三停平等, 富貴榮顯, 三停不均, 孤夭貧賤」. 경계는 自髮際至眉, 眉至準頭, 準頭至地閣.
- 상모궁: 「若還一處無均等, 好惡中間有改更」.
- 복덕궁: 「天地相朝」, 「頦圓額窄, 須知苦在初年」, 「額闊頦尖, 迍否還從晩景」.
- 전택궁: 두 눈이 같은 모양과 크기(「清秀分明一樣同」). 짝이 다를 때의 결과는 원문에 없다.
- 육부: 「兩顴骨 ... 欲其充實相輔, 不欲支離孤露」. 오악: 「中嶽薄而無勢, 則四嶽無主」.
- 오행형: 「金不嫌方, 木不嫌瘦, 水不嫌肥, 火不嫌尖, 土不嫌濁」. 화형은 上尖下闊(위가 좁고 아래가 넓음).
- 유년운기: 麻衣 流年運氣部位歌를 세 곳에서 확인(20대 輔角/司空/邊城/中正/丘陵/冢墓/印堂, 30대 山林부터 少陽, 40대 少陰부터 蘭臺, 50대 廷尉부터 虎耳). 판단은 주로 氣色.
- 콧구멍: 「準頭圓，鼻孔不露」(좋음), 「孔仰露出，夭折寒素」, 「孔仰家無隔宅糧」, 「穴孔大而財不聚」, 콧방울은 廚灶(「兩旁廚灶亦圓齊」). 판본마다 글자가 조금 다르다.
- 못 찾은 것: 一大一小와 눈 높낮이 규칙, 左眼=아버지 식 대응(블로그뿐), 유년 100세 판단 규칙 전체, 神 판별 기준, 한국식 자 측정법.
- 우리 조사 자료(~/Documents/sang-research)는 뉴스, 카페, 블로그 112개로 원전이 아니다. **부위별 성격 문구(`facets.js`, `parts.json`)는 이 대중 풀이에서 왔고 원문 대조를 하지 않았다.**

## 4. 우리의 인위적 개입 (모두 `READING_ENGINE.md`에 상세)

- 삼정: 균등 허용 폭 0.12, 중심 -0.27(코끝 경계 기준의 임시값), 눈썹 선은 눈썹 점 6개 평균.
- 오행형: 점수 식, 중심 5.31과 폭 2.0, 섞임 기준 0.3, 토형 오프셋 1.6.
- 나이: 색(氣色)은 쓰지 않음, 부위 형태만 읽음. 나이대별 부위 배정(山林은 30대).
- 예외: 판정 기준 1.0, 광대 좌우 차이 중심 3.0과 폭 2.0(추측), 결과가 원문에 없는 짝은 결과를 말하지 않음, 눈썹 짝 제외, 이복형제 풀이 없음.
- 눈썹: 앞머리, 문신, 그린 눈썹 때문에 읽지 않는다. `parts.js`에서 눈썹 카드를 빼고, 나이 풀이도 눈썹을 쓰지 않는다(20대는 이마만, 30대는 눈만).
- 얼굴 너비(cm) 문장은 홍채 기준 오차가 커서 삭제함.

## 7. 열린 결정과 남은 일

1. 성격 문구(부위별 풀이)를 마의상법 원문과 대조: 먼저 부위별로 원문 근거가 얼마나 있는지 보고한 뒤 승인받는다. (진행 중)
2. 전시 데이터로 기준값 재설정(삼정 중심, 오행 중심, 광대 좌우). 30건 이상 필요.
3. 3D 깊이: 전시 방문자 기록을 모아 사람 사이 구분이 되는지 다시 본다. 코와 광대 평가를 고른 기록이 필요하다. (보류)
4. 콧구멍 풀이: 원문 근거는 있으나 정면에서 재는 방법이 없다. 대리 지표를 검증하려면 시험지에 평가 항목이 필요하다. (보류)
5. "긴 얼굴" 반복의 원인 확인. (보류)
6. 전시 준비: 전시용 컴퓨터 점검, OpenAI와 Vercel 한도, `?debug=1` 제외 확인, 종료 후 키 교체 또는 Supabase 프로젝트 삭제, 사진 3,274장 저장소 밖으로 이동(전시 후).

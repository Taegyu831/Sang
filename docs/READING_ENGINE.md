# 측정과 읽기 구조

카메라 입력에서 결과 문장까지, 파일마다 맡은 일이 나뉘어 있습니다.

```
카메라 프레임
  pose.js          고개 각도 추정, 얼굴을 정면으로 되돌림
  features.js      정면 좌표에서 비율 계산
  capture.js       쓸 수 있는 프레임만 모아 가중 중앙값으로 수렴
  calibration.js   평균 얼굴 기준값과 한 단계의 크기
  reading.js       전통 틀 세 가지 (삼정, 오안, 오악) 분류
  interpret.js     다섯 주제 읽기 규칙 (content.json 사용)
  content.json     문구, 가중치, 방향, 조합 해석
  app-v3.js        카메라, 화면, 결과 그리기
  debug.js         ?debug=1 기록 화면
```

## 1. 자세 보정 (pose.js)

화면의 2D 좌표는 고개를 돌리면 가로가, 끄덕이면 세로가 줄어듭니다.
눈꼬리, 입꼬리, 광대, 턱 등 좌우 쌍과 위아래 축을 여러 개 평균해 얼굴의 가로, 세로, 앞뒤 축을 만들고,
MediaPipe 표준 얼굴을 정면 기준으로 삼아 현재 얼굴이 얼마나 회전했는지 구한 뒤, 모든 점을 정면 방향으로 되돌려 비율을 계산합니다.
정면 얼굴은 보정 전후 값이 같습니다. 고개 기울기(roll)도 함께 바로잡혀 눈꼬리 각도가 고개 기울기에 흔들리지 않습니다.
한계: 깊이(z)는 모델 추정값이라 각도가 클수록 오차가 남습니다.

## 2. 연속 측정 (capture.js)

정면, 좌, 우 촬영 대신 관람객이 자연스럽게 움직이는 동안 쓸 수 있는 프레임을 모읍니다.
제외: 얼굴이 너무 작거나 크거나 치우침, 좌우 26도, 상하 20도 초과, 웃음, 입 벌림, 눈 깜빡임.
정면에 가깝고 무표정에 가까울수록 큰 비중을 받고, 비율마다 가중 중앙값을 씁니다.
앞뒤 절반의 추정값이 더 이상 달라지지 않으면 스스로 끝납니다.

## 3. 기준값 (calibration.js)

얼굴 메시 위의 평균 얼굴을 기준으로, 평균에서 몇 단계 떨어졌는지로 판단합니다.
메시 상단이 실제 머리선보다 낮아 평균 얼굴의 삼정이 28 / 30 / 41%로 나오기 때문에, 33.3% 같은 교과서 값을 쓰면 평균 얼굴이 "하정 강조"로 읽힙니다.
센터와 한 단계의 크기는 첫 추정이며, 실제 관람객을 `?debug=1`로 기록해 이 파일만 고치면 됩니다.

## 4. 두 층의 읽기

1층, 전통 틀 (reading.js): 어떻게 쟀는가.
- 삼정: 상정 / 중정 / 하정 강조, 균형 (강조는 미세, 완만, 뚜렷 세 단계)
- 오안: 개방 / 응집 / 균형 (좌외, 눈 사이, 우외 세 여백을 같은 비중으로 평균)
- 오악: 구조 / 원만 (턱 너비와 광대 너비 대비 얼굴 길이)

2층, 다섯 주제 (interpret.js + content.json): 무엇을 말하는가.
- 관찰과 판단, 현실과 자원 처리, 표현과 관계, 지속과 전환, 실행과 구조
- 한 주제는 서로 다른 부위의 비율 두세 개를 모아 읽습니다.
- 근거가 둘 이상 같은 방향이면 뚜렷하게, 하나뿐이면 "약한 경향", 평균 가까이면 "균형". 그래서 모든 얼굴이 모든 주제에서 문장을 받습니다.
- 한 주제의 카드는 측정된 사실, 전통 관상에서 보는 영역, 이 얼굴의 읽기, 읽을 때의 한계 순서입니다.
- 두 주제가 모두 뚜렷하게 읽히고 content.json의 조합에 해당하면 "함께 보면" 문장이 붙습니다.
- 눈꼬리와 입꼬리는 주제를 바꾸지 않고 말투 보정으로만 씁니다.

## 5. 문구와 규칙 고치기 (content.json)

코드를 건드리지 않고 고칠 수 있습니다.
- `themes[].features`: 어떤 비율을 쓰는지, 방향(sign), 비중(weight). weight 0이면 끕니다.
- `themes[].states`: 방향별 이름, 읽기 문장, 약한 경향 문장
- `links`: 두 주제가 함께 나올 때 붙는 문장
- `tone`: 눈꼬리, 입꼬리 문장
- 문구에는 줄표(긴 대시)를 쓰지 않습니다. 테스트가 확인합니다.

## 6. 사용법

- 자세 보정 끄고 비교: `?pose=raw`
- 디버그 기록: `?debug=1`
  - 카메라 시작, 기록 시작, 20~30초간 고개를 좌우, 상하로 천천히 움직이고 정지
  - 비율별 흔들림, 각도 10도당 변화, 틀과 주제의 결과 일관성, CSV 저장
  - 영상 위에 측정에 쓰는 점의 이름과 번호가 표시됩니다
- 카메라 없이 결과 화면 보기 (127.0.0.1에서만):
  `?preview=1&v=lowerThird:47,jawCheek:84,mouthNose:2.1` (v를 빼면 평균 얼굴)

## 7. 테스트

서버를 띄우고 브라우저로 열면 결과가 화면에 나옵니다.
```
python3 -m http.server 8765 --bind 127.0.0.1
# http://127.0.0.1:8765/tests/pose.test.html
# http://127.0.0.1:8765/tests/engine.test.html
# http://127.0.0.1:8765/tests/flow.test.html
# http://127.0.0.1:8765/tests/debug.test.html  (디버그 화면 확인용)
```
테스트는 가상 얼굴로 만든 것입니다. 실제 카메라의 깊이 노이즈와 각도 부호는 `?debug=1`로 확인해야 합니다.

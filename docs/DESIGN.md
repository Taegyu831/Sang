# Figma와 코드 협업

[Figma 현재 구현 화면](https://www.figma.com/design/zzQuyeeS0rzyvR8pGNAG61?node-id=8-6601)

- 01 현재 구현 화면: 데스크톱·모바일의 전체 화면과 주요 상태
- 02 공통 컴포넌트: 반복 요소·색상 변수·글꼴 스타일
- 03 디자인 수정안: 직접 디자인을 수정하는 작업 공간

Figma에서 수정한 프레임 링크와 적용 범위를 전달하고, 기존 코드를 수정한 뒤 실제 웹 화면을 확인합니다. 공통 요소의 변경은 관련 화면에 함께 반영합니다.

Figma와 GitHub 코드가 자동으로 실시간 동기화되지는 않습니다. 카메라와 분석 실행은 웹 앱에서 확인합니다.
